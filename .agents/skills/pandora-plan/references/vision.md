# 个人愿景与中期规划

本流程帮助用户在年度页顶部回顾长期方向，并把它逐层转成年度结果：

**个人陈述 / 终身使命 → 3–5 年中期目标 → 年度目标 → 里程碑**

个人陈述、终身使命和 3–5 年中期目标**不另建独立文档**，而是写在本年度索引页最上方的“愿景与中期方向”章节。每年制定年度目标时，先回顾和修订该章节，再检查年度目标是否对齐。上一年度页面保留当年的内容，作为历史快照；新年度页面从上一年承接，经用户确认后更新。不要另建一份平行的“愿景总文档”。

这是一段协作式规划，不是替用户撰写人生答案。每层内容都要区分用户原话、AI 整理稿和待确认建议。用户可以随时修改、跳过某一层或只规划当前最重要的目标。

## 访谈顺序

1. **个人陈述与终身使命**：询问用户希望长期成为什么样的人、希望创造或贡献什么、哪些价值或责任希望长期坚持、哪些方向明确不想追求。允许用户从片段、故事、经历或现有笔记开始，不要求一次写出漂亮的宣言。整理成一段简洁的个人陈述与若干关键词，请用户逐句确认；不要根据仓库示范内容推断用户价值观。
2. **愿景边界**：询问这份愿景适用于哪些生活领域、有哪些现实约束或不可牺牲项、哪些事情目前仍不确定。只保留用户说出的内容；开放问题标注为待探索，而不是擅自补全。
3. **3–5 年中期目标**：询问在用户选择的 3–5 年范围内，哪些可观察的状态或成果能表明愿景正在实现。每个中期目标说明期望结果、依据、适用领域、成功证据、主要假设和不做什么。避免把日常习惯或任务写成目标，也不要擅自设定具体截止日期。
4. **更新年度页顶部方向**：在创建或更新年度索引页时，先回看上年度页面顶部的“愿景与中期方向”，请用户确认个人陈述、终身使命和 3–5 年中期目标是延续、调整还是暂时未知。只把用户确认的当前版本写入本年度页；保留上一年度原文，不回写覆盖历史快照。
5. **对齐年度目标**：对每个中期目标，询问未来 12 个月最有意义且可验证的一步是什么，以及哪些方向暂缓。将已确认的一年期成果映射到对应年度页、领域和年度目标卡；用户尚未确认的内容只保留为候选，不创建目标卡。检查每个年度目标怎样推动上方至少一个方向；新探索的目标应标出理由。
6. **拆分里程碑**：对每个确认的年度目标，拆分少量可验证的阶段结果。仅在用户确认时填目标日期；里程碑用独立卡片并通过 `所属目标` 回链，目标卡用 `里程碑` 列表指向里程碑卡。
7. **回看一致性**：逐层复述愿景如何连接中期目标、年度目标和里程碑，标出没有年度行动承接的中期目标、无法验证的目标、彼此冲突的承诺及待决事项。请用户确认后才写入。

## 写入边界

- 读取现有 PARA 与 Wiki 资料时可调用 `$pandora-query`，但历史资料和 Wiki 摘要只能作为讨论证据，不能代替用户确认。
- 在年度页正文顶部维护愿景和中期方向，不新增属性字段；该章节使用 `13 年度.md` 模板提供的标题与填写提示。年度目标与里程碑按 `references/goals.md` 建在 `20 领域/目标`，并使用现有属性字典和模板。
- 不要把长期愿景塞进一个虚构的领域。领域表示持续责任，中期目标表示阶段成果，年度目标表示一年内可验收的结果，项目表示有明确交付和结束条件的执行工作。
- 用户只提出宽泛想法时，先问一个最有助于推进的问题；每轮问题保持少量，避免一次性抛出整份人生问卷。
- 完成年度目标规划后，核对 `年份`、`年度页`、`领域`、`里程碑` 与里程碑的 `所属目标`，然后报告哪些已确认写入、哪些仍是草案。
