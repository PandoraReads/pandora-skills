# 第二大脑首次上手

仓库根路径（由 pandora-onboard 确认并更新）：`__未绑定__`

首先请用户确认当前打开的 Obsidian 仓库的**绝对路径**。对照该目录下的 `AGENTS.md`、`00 收集箱`、`60 工作台` 和 `90 系统/指南/属性字典.md`，并确认它确实是用户打算使用的副本；不要把创作者电脑的路径或另一个 Obsidian 仓库当作目标。获得用户确认后，在仓库根目录执行 `python3 .agents/scripts/bind_vault.py "<用户确认的绝对路径>"`，再执行同命令加 `--check`，将路径同步到全部八个技能文件及 Apex 设置 `skillSourceFolders`。若复制或搬迁仓库，重新执行绑定。脚本只改技能文件中的路径标记和这一个插件设置值，不改笔记与工作台布局；脚本无法执行时逐个更新八处标记及该设置值并核对。其他技能在执行前必须检查标记是否与当前仓库一致；不一致时先完成这一步。

开始前读根目录 `AGENTS.md`、`开始使用-后续改成 html.md` 和 `90 系统/指南/属性字典.md`。这是交互式引导，不代表替用户创建个人目标或承诺。

1. 路径绑定通过后，确认用户是否已复制文件。材料导入的第一步是将原件复制到 `<仓库根路径>/00 收集箱`，而非先分类或移动原始来源；用户未提供的文件不要自行搜索其电脑其他位置。
2. 用户准备好后，再调用 `$pandora-triage` 整理导入物。含义不明的材料保留在 收集箱。
3. 按用户意愿调用 `$pandora-plan`，分别选择领域、年度目标或项目等事项。每一步解释对应目录和工作台入口；不替用户决定长期领域、年度目标或项目投入。
4. 提醒用户习惯打卡在 Apex 全局小组件中设置；不要为打卡建立仓库文件。
5. 每次对话只推进用户当前选择的一步，勾选 `开始使用-后续改成 html.md` 中已完成的事项，不虚报 Obsidian UI 操作已完成。

已在清单中完成的步骤不要重复执行。遇到用户想跳过某步，继续其明确选择的路径。

## 与 LLM-Wiki 协作

完成 PARA 导入后，向用户说明 `wiki/` 是可选的 AI 知识层；仅在用户选择摄入 `00 收集箱` 或 `30 资源` 的已读资料时调用 `$pandora-ingest`，通常优先从整理好的资源摄入。项目、领域、目标、心愿和日志可用 `$pandora-query` 直接查 PARA，不直接送入 Wiki。可演示从 Wiki 摘要回到资源原文，参考 `90 系统/指南/LLM-Wiki协作规范.md`。
