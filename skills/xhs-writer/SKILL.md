# 小红书图文文案生成

> 五类型模板驱动 + 品牌资产约束，产出直接入 Apex 内容流水线「草稿」阶段。

## 何时使用

- `/xhs-writer 英语学习工具测评`
- "给这条选题出一条小红书图文"
- "写一篇小红书 IP 观点文"

## 执行流程

### 第 1 步：读卡 → 仅补缺（frontmatter 优先）

1. **先读选题卡 / 指令注入的 frontmatter**：`平台`、`内容形式`、`内容类型`、`受众`（及主题/战役）。
2. **`内容类型` 已填则直接采用，不向用户再问**。frontmatter 中文值 → 内部键：
   - `IP观点` → `ip-english-opinion`（人设观点；不限英语）
   - `IP知识` → `ip-knowledge`（干货/方法论；可覆盖成长/一人公司/第二大脑）
   - `营销功能` → `marketing-feature`
   - `营销场景` → `marketing-scenario`
   - `营销教程` → `marketing-tutorial`
3. **仅缺失时**才向用户确认：
   - 内容类型（五选一，上表）
   - 主题/选题（若无卡）
   - **（marketing-* 必填）版本 × 市场**：LME Base/Full/Kids/Medical（国内）或 Global（海外）
   - （可选）关联产品：LME / Apex Dashboard / 第二大脑课程
4. **禁止**改写 `类型`（保持笔记类型「文案」）。交卷时把 `内容类型`（及已有 `受众`）写回草稿 frontmatter。

### 第 2 步：加载模板与品牌资产

必读（vault 相对路径）：
- **当前口径（冲突时以此为准）**：`{{你的仓库}}/00-IP与品牌/品牌记忆-当前口径.md`
- **LME 硬约束**：同仓技能 `/lme-daihuo-constraints`（若已安装）
- 类型模板：`{{你的仓库}}/99-提示词库/xhs-post-{类型}.md`
- 人味化约束：同目录 `xhs-copywriter-humanized.md`
- 标题公式：同目录 `xhs-title-generator.md`
- 品牌资产：同目录 `品牌调性指南.md`、`声音指南.md`、`专家画像与核心观点库.md`

### 第 3 步：生成文案

按所选类型模板的结构生成：
- **标题**：3 个候选（套标题公式，带 emoji，≤20 字）
- **正文**：钩子开头 → 价值主体 → 互动结尾，配 emoji 分段，口语化短句
- **标签建议**：5-8 个（大流量词 + 垂直词 + 产品词）

硬约束：
- 简体中文，人味化（参照 humanized 约束，禁 AI 腔：禁"首先/其次/总而言之"式排比、禁空洞形容词堆砌）
- **FREE/PRICE 规则**（详见 `/lme-daihuo-constraints`）：Base 可说免费/插件市场免费；付费版（Full/Kids/Medical/Global）禁说免费、禁报具体公价（除非用户给出当期活动价），改用限时优惠/领券/试用
- marketing-* 写前必须已确认版本×市场；演示画面若配视频建议：不出镜、实景空镜+大字字幕+AI配音
- 不自动发布、不覆盖人工终稿

### 第 4 步：写入流水线草稿库

路径：`{{你的仓库}}/01-草稿/小红书-{主题slug}.md`
（重名则加类型/日期后缀，禁止覆盖）

frontmatter 按 `{{你的仓库}}/00-内容生产流水线规范` 字段字典：
`类型: 文案`（笔记类型）/ `状态: 进行中` / `status: draft` / `平台: 小红书` /
`内容形式`（图文或短视频，继承选题卡）/ `内容类型`（中文值：IP观点/IP知识/营销功能/营销场景/营销教程）/
`时长`（图文留空；短视频写时长桶）/ `受众`（继承或补写）/ `关联项目`（至少一项）/
`创建时间` / `更新时间` / tags（小红书、内容形式、内容类型）

正文区块：`## 标题候选` + `## 正文` + `## 标签建议` + `## 创作说明`（类型、参考模板、可复用点）+ `## 关联`

### 第 5 步：返回结果

1. 标题候选 + 正文
2. 草稿 wikilink
3. 提醒："已入流水线「草稿」阶段；定稿后移至 `{{你的仓库}}/02-待发布内容` 并改 `status: review` / `状态: 等待中`。"
