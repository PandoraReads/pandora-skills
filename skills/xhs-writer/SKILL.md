# 小红书图文文案生成

> 五类型模板驱动 + 品牌资产约束，产出直接写入 `{{你的仓库}}/内容创作/01-草稿/`（`status: draft`）。

使用前把 `{{你的仓库}}`、`{{你的品牌名}}`、`{{你的产品名}}`、`{{你的账号定位}}`、`{{你的目标人群}}` 换成你自己的路径和名称。产品档位、赠品和价格只写在 `{{你的仓库}}/assets/brand.md`，不写进本技能。

## 何时使用

- `/xhs-writer <主题>`
- "给这条选题出一条小红书图文"
- "写一篇小红书 IP 观点文"

## 执行流程

### 第 1 步：读卡 → 仅补缺（frontmatter 优先）

1. **先读选题卡 / 指令注入的 frontmatter**。选题卡默认在 `{{你的仓库}}/内容创作/00-选题库/`（`status: idea`）。读取 `平台`、`内容形式`、`内容类型`、`受众`（及主题/战役）。
2. **`内容类型` 已填则直接采用，不向用户再问**。frontmatter 中文值 → 内部键：
   - `IP观点` → `ip-english-opinion`（人设观点；不限英语）
   - `IP知识` → `ip-knowledge`（干货/方法论；主题落在 `{{你的账号定位}}` 内）
   - `营销功能` → `marketing-feature`
   - `营销场景` → `marketing-scenario`
   - `营销教程` → `marketing-tutorial`
3. **仅缺失时**才向你确认：
   - 内容类型（五选一，上表）
   - 主题/选题（若无卡）
   - **（marketing-* 必填）版本 × 市场**：`{{你的产品名}}` 的免费版或付费版，以及国内或海外。具体档位名以 `{{你的仓库}}/assets/brand.md` 为准
   - （可选）关联产品：`{{你的产品名}}`
4. **禁止**改写 `类型`（保持笔记类型「文案」）。交卷时把 `内容类型`（及已有 `受众`）写回草稿 frontmatter。受众空着时用 `{{你的目标人群}}`。

### 第 2 步：加载模板与品牌资产

必读：
- **品牌规范（冲突时以此为准）**：`{{你的仓库}}/assets/brand.md`（`{{你的品牌名}}` 的调性、声音、人设观点、产品口径与当前说法）
- 类型模板：`{{你的仓库}}/内容创作/99-内容模板/xhs-post-{类型}.md`
- 人味化约束：同目录 `xhs-copywriter-humanized.md`
- 标题公式：同目录 `xhs-title-generator.md`

品牌规范或类型模板缺失时停下问你，不编造调性、档位或价格。范文、爆款标题、选题灵感和数据案例若要参考，只读 `{{你的仓库}}/assets/素材库/`。

### 第 3 步：生成文案

按所选类型模板的结构生成：
- **标题**：3 个候选（套标题公式，带 emoji，≤20 字）
- **正文**：钩子开头 → 价值主体 → 互动结尾，配 emoji 分段，口语化短句
- **标签建议**：5-8 个（大流量词 + 垂直词 + 产品词）

硬约束：
- 简体中文，人味化（参照 humanized 约束，禁 AI 腔：禁"首先/其次/总而言之"式排比、禁空洞形容词堆砌）
- **FREE/PRICE**：以 `{{你的仓库}}/assets/brand.md` 为准。免费版可说「免费」；付费版禁说免费、禁报具体公价（除非你给出当期活动价），改用限时优惠/领券/试用
- marketing-* 写前必须已确认版本×市场；演示画面若配视频建议：不出镜、实景空镜+大字字幕+AI配音
- 不自动发布、不覆盖人工终稿

### 第 4 步：写入草稿库

路径：`{{你的仓库}}/内容创作/01-草稿/小红书-{主题slug}.md`
（重名则加类型/日期后缀，禁止覆盖）

frontmatter 字段（与所在目录一致）：
`类型: 文案`（笔记类型）/ `状态: 进行中` / `status: draft` / `平台: 小红书` /
`内容形式`（图文或短视频，继承选题卡）/ `内容类型`（中文值：IP观点/IP知识/营销功能/营销场景/营销教程）/
`时长`（图文留空；短视频写时长桶）/ `受众`（继承、补写，或用 `{{你的目标人群}}`）/ `关联项目`（至少一项）/
`创建时间` / `更新时间` / tags（小红书、内容形式、内容类型）

若 `{{你的仓库}}/内容创作/99-内容模板/` 另有字段说明，`status` 仍必须与目录一致：选题卡 `idea`，草稿 `draft`。

正文区块：`## 标题候选` + `## 正文` + `## 标签建议` + `## 创作说明`（类型、参考模板、可复用点）+ `## 关联`

### 第 5 步：返回结果

1. 标题候选 + 正文
2. 草稿 wikilink
3. 提醒："已写入 `{{你的仓库}}/内容创作/01-草稿/`（`status: draft`）。定稿并配图后移至 `{{你的仓库}}/内容创作/02-待发布/`，并改 `status: review`、`状态: 等待中`。"
