# Question Types Design Templates

## 1. Blurting Questions

### Purpose
Activate prior knowledge and create connections to new material

### Template
```
关于 [主题]，你脑子里现存的关联词汇有哪些？请列出 5-10 个。
```

### Guidelines
- Don't give hints or examples
- Encourage any words that come to mind
- Use as baseline for learning progress tracking
- Follow-up: "Which of these are in the article?"

## 2. Prediction Challenges

### Purpose
Build anticipation and contextual guessing skills

### Template
```
请盲猜这些词在文章中可能的含义：[word1], [word2], [word3]
```

### Multiple Choice Format
```
关于 "[word]"，以下哪个意思最可能出现在文章中？
A. [meaning 1]
B. [meaning 2]
C. [meaning 3]
D. [meaning 4]
```

### Guidelines
- Choose 3-4 key vocabulary words
- Provide plausible but incorrect options
- Focus on contextual meaning, not dictionary definitions
- Ask for reasoning after selection

## 3. Summary Questions

### Purpose
Force deep processing and comprehension

### Template
```
用 [目标语言] 总结第 [段落] 的核心观点。
```

### Advanced Template
```
如果不超过 [字数] 个单词，请用 [目标语言] 总结这篇文章的 [aspect]。
```

### Guidelines
- Require target language output
- Set word limits to encourage conciseness
- Focus on main ideas, not details
- Ask for supporting evidence

## 4. Sentence Construction

### Purpose
Apply grammar patterns in personal contexts

### Template
```
请用以下句式结构造一个关于你个人经历的句子：
"[complex_sentence_pattern]"
```

### Context-Specific Template
```
使用 "[grammar_pattern]" 描述你的 Obsidian 工作流。
```

### Guidelines
- Choose patterns from the text
- Relate to user's real life
- Encourage creative application
- Focus on accurate form over creativity

## 5. Multiple Choice Questions

### Purpose
Test vocabulary distinctions and grammar patterns

### Template
```
在刚才的语境中，表示 "[concept]" 最地道的表达是：
A. [option A]
B. [option B]
C. [option C]
D. [option D]
```

### Explanation Template
```
你选择 [答案] 的原因是什么？为什么其他选项不合适？
```

### Guidelines
- Focus on common confusion points
- Include one obviously wrong option
- Include one plausible but incorrect option
- Require justification for answers

## 6. Fill-in-the-Blank Questions

### First Attempt Template
```
填空："[sentence with blank]"
```

### With Hint Template
```
填空（首字母提示）："[sentence with blank]"
答案：[first letter]...
```

### Guidelines
- Blank key vocabulary or grammar words
- Progress from no hints to hints
- Focus on high-value items
- Use context to make answer deducible

## 7. Double Translation Questions

### Forward Template
```
将以下中文翻译成英文："[chinese meaning]"
```

### Reverse Template
```
将以下英文翻译成中文："[english sentence]"
```

### Context Template
```
根据文章内容，"[chinese phrase]" 的英文表达是什么？
```

### Guidelines
- Use authentic language from the text
- Focus on idiomatic expressions
- Require exact text where possible
- Connect to original context

## 8. Review Questions

### Error Review Template
```
回顾：你之前在 [topic] 上犯的错误是什么？为什么？
```

### Synthesis Template
``
综合：[concept A] 和 [concept B] 之间有什么联系？
```

### Guidelines
- Return to previously difficult areas
- Focus on understanding, not just correction
- Ask for improvement strategies
- Connect to broader learning goals

## Question Flow Design

### Pre-Learning Flow
1. Blurting → 2. Prediction → 3. Goal Setting

### In-Learning Flow
1. Summary → 2. Construction → 3. Connection

### Post-Learning Flow
1. MCQ → 2. Fill-in → 3. Translation → 4. Review

## Adaptive Questioning Logic

### Correct Answers (Increase Challenge)
- Ask "Why is this important?"
- Request examples in different contexts
- Compare with related concepts

### Incorrect Answers (Provide Support)
- Give hints before revealing answer
- Ask leading questions
- Suggest review resources

### Mixed Performance
- Vary question types
- Adjust difficulty gradually
- Provide clear progress feedback
