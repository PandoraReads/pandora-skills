# Active Recall Principles

## Core Concepts

Active Recall is a learning method that forces the brain to retrieve information from memory rather than passively absorbing it. This creates stronger neural pathways and improves long-term retention.

### Key Principles

1. **Strain Creates Gain**: The more difficult the retrieval, the stronger the memory
2. **Retrieval > Recognition**: Remembering is more effective than recognizing
3. **Spacing Effect**: Distributed practice over time beats massed practice
4. **Testing Effect**: Testing is learning, not just assessment

## Implementation in Language Learning

### Pre-Learning Phase
- **Blurting Method**: Write down everything you know about a topic before learning
- **Prediction Challenge**: Guess meanings of new words based on context
- **Activate Prior Knowledge**: Connect new information to existing knowledge

### In-Learning Phase
- **Summarization Force**: Require summaries in target language after each section
- **Sentence Construction**: Use complex structures in personal contexts
- **Self-Explanation**: Ask "Why does this make sense?" for each concept

### Post-Learning Phase
- **Mixed Practice**: Combine different question types
- **Spacing**: Review after increasing intervals (1hr, 1d, 1w, 1m)
- **Error Review**: Focus on mistakes as learning opportunities

## Cognitive Load Theory Application

### Intrinsic Load
- Core concepts that must be learned
- Minimize with chunking and scaffolding

### Extraneous Load
- Irrelevant information that distracts from learning
- Eliminate through clear instructions and examples

### Germane Load
- Load related to schema construction and automation
- Maximize through spaced repetition and varied practice

## Socratic Questioning Framework

### Opening Questions
- What do you already know about this?
- What do you predict this will be about?
- What questions do you have before reading?

### Probing Questions
- Why do you think that?
- How does this connect to what you learned before?
- What would happen if...?

### Closing Questions
- What are the key takeaways?
- How would you teach this to someone else?
- What questions still remain?

## Question Design Principles

### Effective Questions
- Open-ended rather than multiple-choice when possible
- Require application, not just recall
- Connect to real-world contexts
- Build on previous knowledge

### Question Sequence
- Start with easy retrieval (activation)
- Progress to application and analysis
- End with synthesis and evaluation
- Include review questions at the end
